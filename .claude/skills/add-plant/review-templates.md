# Review templates

**Chat (one plant).** One table per timing group of regions; same rows,
dates per group in columns when regions differ only by timing:

| # | Reminder | Group A | Group B | … | Organic (first) | Chemical alternative | Why |
|---|---|---|---|---|---|---|---|

Then: dose table by age (if any), conditional items, and phases:

| Phase | Group A | Group B | … | Avoid | Watch |
|---|---|---|---|---|---|

State `grownIn`, which regions share (`sameAs`) and why, and the sources.
Mark uncertain lines "(check)".

**Claude Doc (batch).** One section per family with the same tables; the
owner comments inline; apply every correction before writing data.

Nothing is written to a data file before the owner's explicit yes.
