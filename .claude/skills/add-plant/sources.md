# Sources (in order of preference)

1. **ICAR institutes** for the crop — e.g. CISH Lucknow (mango, guava),
   NRC Litchi Muzaffarpur, NRC Banana Tiruchirappalli, NRC Pomegranate
   Solapur, CCRI Nagpur (citrus), IIHR Bengaluru (many fruits, vegetables,
   flowers), CPCRI Kasaragod (coconut).
2. **State agricultural university packages of practice** for the region —
   e.g. BAU Sabour (Bihar), JNKVV (MP), NAU/AAU (Gujarat), Dr BSKKV Dapoli
   (Konkan), MPKV Rahuri (Maharashtra), UAS Bengaluru, TNAU, KAU (Kerala),
   PAU (Punjab), GBPUAT (Uttarakhand).
3. **KVK and state horticulture department advisories.**

Record the sources used in the family file's `sources`. Chemicals: only
those with a label claim for that crop (CIB&RC); never banned products.
